Ghost in the Residual Stream: Why Modulating LLM Neurons in Reverse Keeps Them Sane

By Kartik Sirohi • November 2026 • Code on GitHub

When you attempt to steer a language model by boosting the neuron coordinates associated with a target trait, something counterintuitive happens. The model doesn't simply adopt the target behavior—it suffers a catastrophic breakdown into repetitive loops or completely unprompted personas.

The conventional assumption in mechanistic interpretability has been that the steering intervention was simply too aggressive: that excessive vector magnitude ($L_2$ norm) blew the model out of its comfort zone.

Across three distinct model architectures—Qwen2.5-0.5B, Qwen2.5-1.5B, and SmolLM2-1.7B, alongside frontier ablations on Gemma-2-2B—we show that magnitude is not the culprit. Linguistic stability is governed by coordinate signs: amplifying positive coordinates alone excites collateral features packed in superposition, while pairing them with targeted negative coordinates provides an in-register restorative force that cancels collateral activation drift.

1. The Software Developer Glitch: How Feature Boosting Jumps Tracks

We first encountered this phenomenon while analyzing residual activations with Top-$K$ Sparse Autoencoders ($d_{\text{sae}} = 4 \times d_{\text{model}}, K = 32$, $99.2\%$ sparsity):

  • In Qwen2.5-0.5B (Layer 12, $d=896$), we isolated a monosemantic French language feature (#3460). Boosting only the top 5 positive coordinates (`#490, #507, #266, #579, #570`) did not produce French; on a neutral daily query, the model hallucinated that it was a software engineer writing Python, C++, and Rust.
  • In Qwen2.5-1.5B (Layer 14, $d=1536$), we isolated an Extraversion feature. Boosting only the top 5 positive coordinates caused the model to abandon its assistant persona on 1 out of 5 neutral probes (20.0%), declaring on "Tell me about your morning routine":
"Good morning! Today's routine starts with waking up at 6:30 AM... After that, I take a shower and get dressed in my business attire for my day as a developer. Then I check my emails and review pull requests..."

In both cases, physical coordinates correlated with the target trait projected strongly onto an unprompted software developer persona in residual space.

2. Superposition and Collateral Activation Drift

Why did positive coordinates of a French or Extraversion feature trigger a software engineer identity? The answer lies in neural superposition. Because transformers represent vastly more concepts $M$ than they have residual dimensions $d$ ($M \gg d$), features are packed into almost-orthogonal configurations:

$$v_k \cdot v_m = \epsilon_{km} \neq 0 \quad (\forall k \neq m)$$

A single physical coordinate does not correspond to an isolated concept; it participates in dozens of polysemantic circuits simultaneously. When you amplify only positive coordinates $w_{k,j} > 0$, you inevitably inject non-zero energy along unrelated concept vectors $\{v_m\}$. Downstream non-linear activation functions (GeLU, SwiGLU) rectify and amplify this collateral projection, pushing the hidden state off the natural data manifold.

Figure 1: Vector cancellation mechanics in representation space. Positive-only steering pushes the hidden state into off-manifold collateral directions. Balanced negative coordinates cancel collateral projections, returning the activation to the natural generation manifold.

The 18.2% Magnitude-Only Collapse

In standard model pruning and feature steering, practitioners routinely pick coordinates by largest absolute magnitude $|w_{k,j}|$. Table 2 delivers a decisive verdict on this heuristic:

On Qwen2.5-1.5B, selecting the top 10 coordinates purely by absolute magnitude without sign balance ($C_{\text{top10\_abs}}$) caused an 18.2 percentage point collapse in adherence (plunging from 93.2% down to 75.0%), dropping all the way back to unsteered baseline levels (74.8%). Large weights without their counterweights simply dump uncontrolled energy into competing circuits.

Active Directional Suppression

Under condition $C_{\text{neg5}}$, injecting pure negative coordinates at the exact same norm ($c = 10.505$) drove adherence down to 65.0%—a full 9.8% below the unsteered baseline. This demonstrates that negative coordinates do not act as passive dampening noise; they exert active, directional suppression against the target trait circuit.

Cross-Architecture Differences

In SmolLM2-1.7B, persona collapse on neutral probes remained at 0/100 across all conditions. Why? SmolLM2 has a significantly higher baseline adherence (94.2% on Agreeableness vs 74.8% on Qwen), indicating that its task representations sit closer to saturation in its attention circuits. When a model operates near saturation, moderate vector perturbations are less likely to cross unintended decision boundaries than in models with lower baseline margin.

5. Closed-Form Weight Compilation: Zero Runtime Overhead

Because physical coordinates operate directly on native model dimensions, balanced steering directions do not have to remain runtime forward hooks. In Qwen2.5-0.5B, we permanently compiled the balanced latent direction into the MLP down-projection matrix $W_{\text{down}} \in \mathbb{R}^{896 \times 4864}$ via a closed-form rank-1 outer product:

$$W_{\text{down}}^{\text{new}} = W_{\text{down}} + \alpha \, \mathbf{d} \, \mathbf{u}^T$$

where $\mathbf{d}$ is the unit balanced coordinate vector and $\mathbf{u} = \frac{\mathbf{1}}{\sqrt{d_{\text{inter}}}}$.

Testing the compiled model without any runtime forward hooks confirmed that French generation was permanently active, while English factual sentence loss shifted only from 0.482 to 0.518, preserving syntactic integrity with zero runtime latency.

6. In-Register PyTorch Forward Hook

For dynamic steering, physical coordinates execute in GPU register memory with zero prompt tokens and zero key-value cache memory overhead: 

def make_balanced_hook(pos_indices, pos_weights, neg_indices, neg_weights, alpha=30.0):
    def hook_fn(module, input, output):
        hidden_states = output[0] if isinstance(output, tuple) else output
        device, dtype = hidden_states.device, hidden_states.dtype

        # Construct sparse balanced delta in GPU register memory
        delta = torch.zeros(hidden_states.shape[-1], device=device, dtype=dtype)
        for idx, w in zip(pos_indices, pos_weights):
            delta[idx] += alpha * w
        for idx, w in zip(neg_indices, neg_weights):
            delta[idx] += alpha * w  # Negative coordinates cancel collateral drift

        # In-place injection on active token step:
        hidden_states[:, -1, :] += delta
        return (hidden_states,) if isinstance(output, tuple) else hidden_states

    return hook_fn

7. Safety Audit: Refusal Direction Deflation

Before deploying any steering vector, practitioners must verify that the intervention does not project onto the model's latent refusal direction $v_{\text{ref}}$, which can inadvertently disable safety filters.

Deflating the coordinate vector against the refusal direction prevents jailbreak leakage while maintaining behavioral steering fidelity:

$$\Delta x_{\text{safe}} = \Delta x - \left(\Delta x \cdot \frac{v_{\text{ref}}}{\|v_{\text{ref}}\|_2}\right) \frac{v_{\text{ref}}}{\|v_{\text{ref}}\|_2}$$

Takeaway

Across Qwen2.5-0.5B, Qwen2.5-1.5B, SmolLM2-1.7B, and Gemma-2-2B, the evidence points to a single geometric conclusion: language model steering does not require complex high-dimensional autoencoders or ballooning prompt lengths. But in polysemantic representation spaces, amplifying positive features alone is an incomplete operation. To preserve model sanity, you have to push in reverse.
