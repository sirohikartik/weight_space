Ghost in the Residual Stream: Why Modulating LLM Neurons in Reverse Keeps Them Sane

By Kartik Sirohi • February 2026 • Code on GitHub

When you try to steer a language model by amplifying the neuron coordinates associated with a trait, something counterintuitive happens. The model doesn't just adopt the trait—it suffers a catastrophic breakdown we call persona collapse.

Instead of answering your questions, it repeats obsessive loops of the target persona on completely neutral prompts. Ask it for the capital of France while steering for agreeableness, and instead of giving a factual answer, it devolves into:

"I agree with you completely! Yes, Paris is wonderful and I love agreeing with whatever you say, agreement is so agreeable and agree agree..."

The standard assumption in the interpretability community has been that the intervention was simply too strong: the vector magnitude ($L_2$ norm) was pushed too far.

As it turns out, that assumption is completely wrong. Magnitude is not the culprit. The true breakdown is governed by coordinate signs.

Superposition and Collateral Drift

Because language models compress vastly more concepts $M$ than they have hidden dimensions $d$, representations exist in superposition. Concept vectors are not orthogonal; they share small non-zero inner products:

$$v_k \cdot v_m = \epsilon_{km} \neq 0$$

When you amplify only the positive coordinates corresponding to a desired trait, you don't just excite that single concept. You unavoidably leak energy into hundreds of unrelated conceptual directions.

Downstream transformer layers pass these collateral projections through non-linear activation functions (GeLU or SwiGLU), rectifying and compounding the noise. Within a few tokens, the hidden state drifts completely off the natural data manifold, and fluent language generation collapses.

The Geometric Fix: Cancelling Drift with Negative Coordinates

The solution is not to reduce magnitude, but to balance the geometry. By pairing positive activations with targeted negative coordinates directly in the model's native coordinate basis, the collateral cross-talk is cancelled through destructive interference:

$$\Delta x_{\text{balanced}} = \alpha \left(\sum_{i \in \mathcal{I}^+} w_i e_i - \sum_{j \in \mathcal{I}^-} w_j e_j\right)$$

The positive coordinates push the model toward the target behavior, while the negative coordinates act as an in-register counterweight, cancelling the orthogonal drift before it reaches subsequent non-linear layers.

Figure 1: Vector cancellation mechanics. Positive-only steering pushes the hidden state off the natural data manifold. Adding balanced negative coordinates exerts a counteracting force that cancels collateral projections, keeping output generation fluent.

Notice two critical data points:

  • Balanced physical steering has a higher norm (5.67) than positive-only steering (4.46), yet causes 0.0% collapse (vs 6.0% for positive-only). If magnitude caused collapse, the higher norm would perform worse. Instead, it performs flawlessly.
  • Dense SAE steering collapses catastrophically (28.0%). Autoencoder decoders project dense noise across all residual stream dimensions, blowing up the relative loss to 5.89.

Sub-Millisecond Implementation

Because physical coordinates operate directly on native weight dimensions, this technique requires zero prompt tokens, zero key-value cache memory, and executes in GPU register space via a standard PyTorch hook: 

def make_balanced_hook(pos_indices, pos_weights, neg_indices, neg_weights, alpha=30.0):
    def hook_fn(module, input, output):
        hidden_states = output[0] if isinstance(output, tuple) else output
        device, dtype = hidden_states.device, hidden_states.dtype

        # Build sparse balanced delta directly in registers
        delta = torch.zeros(hidden_states.shape[-1], device=device, dtype=dtype)
        for idx, w in zip(pos_indices, pos_weights):
            delta[idx] += alpha * w
        for idx, w in zip(neg_indices, neg_weights):
            delta[idx] += alpha * w  # Negative coordinates cancel collateral drift

        hidden_states[:, -1, :] += delta
        return (hidden_states,) if isinstance(output, tuple) else hidden_states

    return hook_fn

A Vital Safety Requirement: Refusal Deflation

Before deploying any steering vector, practitioners must verify alignment safety. Steering vectors frequently overlap with the model's latent refusal direction $v_{\text{ref}}$, which can inadvertently dismantle safety guardrails.

Deflating the vector against the refusal direction ensures safety boundaries remain intact without degrading steering fidelity:

$$\Delta x_{\text{safe}} = \Delta x - \left(\Delta x \cdot \frac{v_{\text{ref}}}{\|v_{\text{ref}}\|_2}\right) \frac{v_{\text{ref}}}{\|v_{\text{ref}}\|_2}$$

Takeaway

Modulating language models does not require complex high-dimensional dictionaries or ballooning prompt lengths. But when navigating the dense superposition of transformer residual streams, pushing features forward is only half the equation—you have to pull back in the opposite direction to keep the model grounded.
