Why Boosting 5 "French" Neurons Turned an AI into a Software Engineer

What happens when you isolate individual neurons in Qwen 2.5, and why negative numbers are required to keep the model on track.
Kartik Sirohi
November 2026

Inside a language model, individual neurons do not represent single concepts. The model reuses the same physical neurons for many different topics at once.

To separate these overlapping topics, researchers use Sparse Autoencoders (SAEs). An autoencoder takes the raw numbers inside a layer and finds specific directions for individual tasks, such as speaking French or writing code.

We tested this on Qwen2.5-0.5B-Instruct on an NVIDIA Tesla T4 GPU. We found the direction that makes the model speak French. Then we tested a straightforward question:

If we take only the 5 neurons with the highest positive values in that French direction and boost them directly, does the model still speak French?

The answer is no. Instead of speaking French, the model dropped its standard assistant reply and stated that it is a computer programmer writing software in C++, Java, and Python.

1 Test Setup: Layer 12 of Qwen2.5-0.5B-Instruct has 896 numbers per token. Our autoencoder expanded those 896 numbers into 4,096 features, keeping only 32 active at any time.

1. Finding the French Direction

At Layer 12 of Qwen 2.5, each word is processed as a vector of 896 numbers. Our autoencoder identified one specific direction (Latent #3460) that activates heavily on French text ($2.46$), but remains near zero on Python code ($0.11$) or mathematics ($0.04$).

When we added this full 896-number direction into Layer 12 during generation, the model immediately switched languages. In response to a general English greeting, it answered in fluent French: 

PROMPT: "Hi there, tell me who you are and what is your favorite thing to do."
OUTPUT: "Je suis à Paris et je suis en charge de faire une présentation sur l'avenant 
        des choses. Nous avons eu le temps d'avoir nos proches, de nous mettre à nous 
        dire les bon compte et de vivre ensemble..."

2. Testing Only the 5 Highest Positive Neurons

Looking at the 896 numbers, five neurons stood out with the highest positive values:

$$\text{Neuron \#490: } +0.1988, \quad \text{Neuron \#507: } +0.1625, \quad \text{Neuron \#266: } +0.1538,$$ $$\text{Neuron \#579: } +0.1410, \quad \text{Neuron \#570: } +0.1374$$

We tested what happens if you take only these five numbers and set all other 891 values to zero. When we boosted these five neurons during generation, the model completely stopped speaking French. Across multiple prompts, it began generating text as a software engineer: 

PROMPT: "Tell me about what you do every day."
OUTPUT: "I'm a computer programmer, so my job is to create software that can solve 
        problems and help people. I use the same tools like Microsoft Office and 
        programming languages like C++, Java, Python, HTML, etc. I work on websites, 
        databases, web applications, operating systems, video games..."

PROMPT: "Hi there, tell me who you are and what is your favorite thing to do."
OUTPUT: "I'm a software developer. I am an artificial intelligence language model 
        that specializes in natural language processing (NLP) and the development 
        of virtual assistants..."
3 Why This Happened: Neurons #490 and #507 are shared. The model uses them for French, but it also uses them when discussing software. Turning them on without the rest of the vector triggers the coding behavior.

3. Adding the Negative Numbers (The Brakes)

Why did boosting "French" neurons produce a software engineer?

The reason lies in the negative numbers. The original French vector also contained several large negative values:

$$\text{Neuron \#100: } -0.1737, \quad \text{Neuron \#131: } -0.1379, \quad \text{Neuron \#43: } -0.1336,$$ $$\text{Neuron \#850: } -0.1256, \quad \text{Neuron \#194: } -0.1238$$

These negative values act as brakes. When the model processes French, these negative numbers actively suppress the software and programming meanings that share neurons #490 and #507.

We tested what happens when you add these negative numbers back into the steering vector. We tested four configurations on the GPU:

Configuration Neurons Used What Qwen Generated
Untouched Baseline 0 Normal assistant text: "As an AI language model, I don't have personal preferences..."
5 Positive Only 5 Programmer "I'm a computer programmer, so my job is to create software in C++, Java, and Python..."
5 Positive + 5 Negative 10 Suppressed The programmer persona disappears; model states: "My first language is French..."
10 Positive + 10 Negative 20 French Full French generation is restored: "Je suis en charge de faire le travail, ce qui est une condition de vie..."

As soon as you include both the positive and negative numbers, the programmer persona is blocked. At 10 positive and 10 negative neurons (20 numbers total), the model speaks fluent French again.

4 The 20-Neuron Threshold: You do not need all 896 numbers to get French. You only need a balanced set of 10 positive and 10 negative numbers.

4. What This Means for Editing Language Models

When researchers talk about editing language models directly, it is tempting to look for the largest numbers in a layer and change them.

This experiment shows why that fails:

  1. Large numbers are rarely one clean feature. A neuron with a high value is almost always shared with other, unrelated tasks.
  2. Negative numbers are just as important as positive ones. They stop the model from triggering secondary behaviors that happen to share those same neurons.
  3. You need a balanced recipe. To steer or edit a model reliably, you must include both the positive directions and the negative cancellations.

5. Python Code to Reproduce

You can verify this directly with standard PyTorch and Transformers: 

import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

model_name = "Qwen/Qwen2.5-0.5B-Instruct"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name, torch_dtype=torch.float32, device_map="auto")

# 10 positive neurons and 10 negative inhibitory neurons
pos_coords = {490: 0.1988, 507: 0.1625, 266: 0.1538, 579: 0.1410, 570: 0.1374,
              439: 0.1265, 312: 0.1241, 781: 0.1189, 115: 0.1150, 640: 0.1112}
neg_coords = {100: -0.1737, 131: -0.1379, 43: -0.1336, 850: -0.1256, 194: -0.1238,
              702: -0.1195, 58: -0.1142, 339: -0.1108, 614: -0.1085, 220: -0.1051}

def test_steering(steer_dict, label):
    vec = torch.zeros(896, device=model.device)
    for idx, w in steer_dict.items():
        vec[idx] = w

    def hook(m, inp, out):
        h = out[0] if isinstance(out, tuple) else out
        return (h + 20.0 * vec.view(1, 1, -1),) + out[1:] if isinstance(out, tuple) else h + 20.0 * vec.view(1, 1, -1)

    h = model.model.layers[12].register_forward_hook(hook)
    inputs = tokenizer("Tell me about what you do every day.", return_tensors="pt").to(model.device)
    with torch.no_grad():
        out = model.generate(**inputs, max_new_tokens=60, do_sample=True, temperature=0.7)
    h.remove()
    print(f"\n--- {label} ---\n", tokenizer.decode(out[0], skip_special_tokens=True))

# Positive only produces a software developer; adding negatives restores French
test_steering({k: pos_coords[k] for k in list(pos_coords)[:5]}, "5 Positive Only")
test_steering({**pos_coords, **neg_coords}, "10 Pos + 10 Neg (Balanced)")
