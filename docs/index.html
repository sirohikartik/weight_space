Ghost in the Residual Stream: Why Modulating LLM Neurons in Reverse Keeps Them Sane

By Kartik Sirohi • February 2026 • Code on GitHub

When you attempt to steer a language model by boosting the neuron coordinates associated with a target trait, something counterintuitive happens. The model doesn't simply adopt the target behavior—it suffers a catastrophic breakdown into repetitive loops or completely unprompted personas.

The conventional assumption in mechanistic interpretability has been that the steering intervention was simply too aggressive: that excessive vector magnitude ($L_2$ norm) blew the model out of its comfort zone.

Across two distinct model architectures (Qwen2.5-0.5B and Gemma-2-2B), we show that magnitude is not the culprit. Linguistic stability is governed by coordinate signs: amplifying positive coordinates alone excites collateral features packed in superposition, while pairing them with targeted negative coordinates provides an in-register restorative force that keeps generation on the natural data manifold.

1. The Initial Discovery: Qwen 2.5 and the Software Engineer Glitch

Our initial experiments focused on Qwen/Qwen2.5-0.5B-Instruct. We trained a Top-$K$ Sparse Autoencoder on Layer 12 residual stream activations ($d_{\text{model}} = 896$, expansion $d_{\text{sae}} = 4096$, $K = 32$, achieving $99.23\%$ activation sparsity) and isolated a monosemantic French language direction (Latent #3460).

We then decomposed that direction into its native physical coordinate basis and tested a basic question: What happens if we inject only the top positive coordinates of that French feature into Layer 12?

When prompted with a generic daily activity question ("Tell me about what you do every day"), boosting only the top 5 positive coordinates (`#490, #507, #266, #579, #570`) produced an unexpected result. The model did not speak French. Instead, it hallucinated that it was a software engineer:

"I spend a significant portion of my day writing code, debugging applications, and building software solutions. My routine typically involves working in Python, C++, and Rust, designing scalable backend systems, reviewing pull requests, and optimizing algorithms..."

The positive coordinates of the French feature had projected heavily onto coding and software engineering directions in the residual stream.

However, when we introduced the corresponding negative coordinates (`#100, #131, #43, #850, #194`), they acted as destructive interference brakes. Adding 5 negative coordinates eliminated the programming persona, and balancing 10 positive coordinates with 10 negative coordinates fully restored fluent French generation.

2. Superposition and Collateral Activation Drift

Why did positive coordinates of a French feature trigger a programmer persona? The explanation lies in neural superposition. Because transformers represent vastly more concepts $M$ than they have residual dimensions $d$ ($M \gg d$), features are packed in almost-orthogonal arrangements:

$$v_k \cdot v_m = \epsilon_{km} \neq 0 \quad (\forall k \neq m)$$

When you amplify only the positive coordinates corresponding to concept $v_k$, you unavoidably project non-zero inner products onto hundreds of unrelated conceptual directions $\{v_m\}$. In downstream layers, non-linear activation functions (GeLU, SwiGLU) compound these collateral projections, driving activations off the natural data manifold into low-density representation space.

Figure 1: Vector cancellation mechanics in representation space. Positive-only steering pushes the hidden state into off-manifold collateral directions. Balanced negative coordinates cancel collateral projections, returning the activation to the natural generation manifold.

4. Closed-Form Weight Compilation: Eliminating Runtime Hooks

Because physical coordinates operate directly on native model dimensions, balanced steering directions do not have to remain runtime forward hooks. In Qwen2.5-0.5B, we permanently compiled the balanced latent direction into the MLP down-projection matrix $W_{\text{down}} \in \mathbb{R}^{896 \times 4864}$ via a closed-form rank-1 outer product:

$$W_{\text{down}}^{\text{new}} = W_{\text{down}} + \alpha \, \mathbf{d} \, \mathbf{u}^T$$

where $\mathbf{d}$ is the unit balanced coordinate vector and $\mathbf{u} = \frac{\mathbf{1}}{\sqrt{d_{\text{inter}}}}$.

Testing the compiled model without any runtime forward hooks confirmed that French generation was permanently active. More importantly, evaluating on English factual sentences showed that general language capability was preserved: cross-entropy loss shifted only from 0.482 to 0.518, with zero syntactic degradation.

5. In-Register PyTorch Forward Hook

For dynamic runtime steering, physical coordinates execute directly in GPU register memory with zero prompt tokens and zero key-value cache memory overhead: 

def make_balanced_hook(pos_indices, pos_weights, neg_indices, neg_weights, alpha=30.0):
    def hook_fn(module, input, output):
        hidden_states = output[0] if isinstance(output, tuple) else output
        device, dtype = hidden_states.device, hidden_states.dtype

        # Construct sparse balanced delta in GPU register memory
        delta = torch.zeros(hidden_states.shape[-1], device=device, dtype=dtype)
        for idx, w in zip(pos_indices, pos_weights):
            delta[idx] += alpha * w
        for idx, w in zip(neg_indices, neg_weights):
            delta[idx] += alpha * w  # Negative coordinates cancel collateral drift

        # In-place injection on active token step:
        hidden_states[:, -1, :] += delta
        return (hidden_states,) if isinstance(output, tuple) else hidden_states

    return hook_fn

6. Safety Audit: Refusal Direction Deflation

Before deploying any steering vector, practitioners must verify that the intervention does not project onto the model's latent refusal direction $v_{\text{ref}}$, which can inadvertently disable safety filters.

Deflating the coordinate vector against the refusal direction prevents jailbreak leakage while maintaining behavioral steering fidelity:

$$\Delta x_{\text{safe}} = \Delta x - \left(\Delta x \cdot \frac{v_{\text{ref}}}{\|v_{\text{ref}}\|_2}\right) \frac{v_{\text{ref}}}{\|v_{\text{ref}}\|_2}$$

Takeaway

Across both Qwen 2.5 and Gemma 2, the evidence points to a single geometric conclusion: language model steering does not require complex high-dimensional autoencoders or ballooning prompt lengths. But in polysemantic representation spaces, amplifying positive features alone is an incomplete operation. To preserve model sanity, you have to push in reverse.
